# weather-app-based-on-restful-APIs

Weather Dashboard 🌦️

A real-time weather dashboard built using Asynchronous JavaScript, Fetch API, and RESTful APIs.
This application allows users to search for any city and instantly view live weather information such as temperature, humidity, wind speed, and weather conditions.

🚀 Project Overview

The Weather Dashboard demonstrates how to work with:

Asynchronous JavaScript (async/await)
RESTful API integration
Fetch API for HTTP requests
JSON parsing and dynamic DOM manipulation
Error handling for failed API calls
Real-time weather updates based on user input

The app fetches live weather data from a public weather API and dynamically updates the user interface.
